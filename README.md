🐺🐐🥬 Волк, Коза и Капуста: поисковые алгоритмы для классической логической задачи
Данный проект реализует классическую логическую головоломку «Волк, коза и капуста» с расширением до пяти сущностей (добавлены лиса и кролик).
Цель игрока — переправить всех персонажей через реку на лодке, соблюдая ограничения, при которых определённые пары не могут оставаться без присмотра человека.

Проект демонстрирует применение различных алгоритмов поиска решений в пространстве состояний. Он может быть полезен для изучения методов искусственного интеллекта, сравнительного анализа алгоритмов и практической реализации конечных автоматов.

🧠 Алгоритмы поиска
В проекте реализованы и сравниваются следующие алгоритмы:

🔍 Поиск в глубину (DFS) — с эвристикой и без неё

🌊 Поиск в ширину (BFS) — с эвристикой и без неё

🌿 Метод ветвей и границ (Branch and Bound, BnB)

⚖️ Поиск по стратегии равных цен (UCS)

🔄 Двунаправленный поиск (Bidirectional Search)

Эвристики настраиваются и позволяют оценить влияние информированности на скорость нахождения оптимального пути.

📦 Структура проекта
solvers/ — реализации алгоритмов поиска

wolf_goat_cabbage.py/enviroment/ — базовая среда для классической задачи (3 персонажа)

wolf_goat_cabbage_fox_rabbit_human/enviroment/ — расширенная среда (5 персонажей)

analyze/ — скрипты для сбора статистики и сравнения алгоритмов

main.py — точка входа, выбор режима (игра или автоматическое решение)

requirements.txt — зависимости (при необходимости)
